Put your profile picture in this folder and name it:  profile.jpg

Tips
- Portrait or square photo, at least 800 x 880 px, under ~500 KB.
- A different file name or type (for example profile.png) works too:
  change the "photo" value in src/app/data/portfolio.data.ts to match.
- Until the file exists, the site shows a "CS" placeholder in the photo frame.
